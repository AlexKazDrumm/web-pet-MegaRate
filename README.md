# MegaRate

Веб-приложение для ведения личного каталога фильмов, сериалов и анимации. Для каждой записи сохраняются статус просмотра и личная оценка, а рейтинги нескольких кинокаталогов собираются в одну карточку и усредняются.

## Возможности

- добавление, редактирование и удаление записей;
- фильтрация по типу и поиск по названию;
- сортировка по названию и средней оценке;
- получение подсказок, описаний и постеров из поддерживаемых каталогов;
- обновление IMDb, Кинопоиска, MyShows, Rotten Tomatoes, Metacritic и World-Art;
- отдельные статусы для просмотренного и списка на будущее.

## Стек

- `frontend` — React, TypeScript, Vite;
- `backend` — Express, TypeScript, TypeORM;
- PostgreSQL — хранение каталога и оценок;
- Docker Compose — запуск приложения и PostgreSQL.

## Запуск в Docker

```bash
copy .env.example .env
docker compose up --build
```

После запуска интерфейс доступен по адресу `http://localhost:8080`, API — `http://localhost:4000`, проверка состояния — `http://localhost:4000/health`.

Ключи `KINOP_API500_KEY` и `KINOP_API200_KEY` нужны только для поиска по Кинопоиску. Остальная часть каталога работает без них.

## Запуск для разработки

```bash
cd backend
npm ci
copy .env.example .env
npm run dev
```

```bash
cd frontend
npm ci
copy .env.example .env
npm run dev
```

Для backend требуется PostgreSQL и строка подключения `DATABASE_URL`. При старте Docker-контейнера миграции применяются автоматически; вручную их можно выполнить командой `npm run migration:run`.

## Команды

```bash
cd backend
npm test
npm run build

cd ../frontend
npm run typecheck

```

## Источники данных

Приложение обращается к публично доступным страницам сторонних каталогов. Формат этих страниц может меняться, поэтому отдельные парсеры при необходимости обновляются независимо. Названия сервисов и товарные знаки принадлежат их владельцам.
